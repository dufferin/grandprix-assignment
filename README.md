# Grandprix Assignment · Platform + CRM

เปิดใช้งาน: **https://dufferin.github.io/grandprix-assignment/**

Demo หน้าเดียว (HTML + JavaScript) ข้อมูลทั้งหมดเป็นตัวอย่าง เก็บไว้ในเบราว์เซอร์ของผู้เปิด (localStorage)

## ขอบเขต

| ส่วน | มีอะไร |
|---|---|
| **Platform Console** | ลูกค้า (tenant) ทุกราย · แพ็ก Basic / Plus · โมดูลที่เปิด · ค่าแพ็กต่อปี · ตั้งค่าแบรนด์ / โดเมน / LINE OA ของแต่ละราย |
| **Login กลาง (Grandprix Account)** | สมัคร / เข้าสู่ระบบด้วย LINE หรืออีเมล + OTP · ความยินยอมแยก 3 ข้อ |
| **บัญชีของฉัน** | ข้อมูลส่วนตัว · ที่อยู่ & ใบกำกับภาษี · กิจกรรมรวมทุกงาน · ระดับสมาชิก |
| **LINE OA (จำลอง)** | rich menu · เชื่อมบัญชี · ตั๋ว QR |
| **Back-office · ภาพรวม** | ลูกค้าทั้งหมด · มาหลายงาน · ยินยอมรับข่าวสาร · เชื่อม LINE · แยกตามงาน · ระดับสมาชิก · Top spender |
| **Back-office · ลูกค้า (CRM)** | รายชื่อ (ตาราง / Kanban / ปฏิทิน / แกลเลอรี) · Top spender · Customer 360 · ระดับสมาชิก · กลุ่มลูกค้า |
| **Back-office · ตั้งค่า** | แพ็กเกจรายปี · โควตา · ใบแจ้งหนี้ค่าแพ็ก |

ไม่อยู่ในขอบเขตนี้: Marketplace · หน้าเว็บของแต่ละงาน · ร้านค้า / คำสั่งซื้อ / การจัดส่ง · การตลาด
